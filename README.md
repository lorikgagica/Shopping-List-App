# 🛒 Shopping List App

A simple Python console application for managing your shopping list—now with item modification, file saving/loading, and an easy-to-use menu.

---

## ✨ Features

- **Add Items:** Easily add new products to your shopping list.
- **Remove Items:** Remove any item by name.
- **Modify Items:** Change any existing item by selecting its number.
- **View List:** See all your current shopping items, neatly numbered.
- **Clear List:** Start fresh any time with one button.
- **Persistent Storage:**  
    - Your shopping list is automatically loaded from `shopping_list.txt` at startup (if it exists).
    - Easily save your finished list to the same file on exit—so you never lose your work!

---

## 🚀 How to Run

1. Make sure Python is installed on your computer.
2. Save the script (e.g. as `shopping_list.py`) in a folder where you want your list to be saved.
3. Open a terminal or command prompt and navigate to the folder.
4. Start the app: `python shopping_list.py`
